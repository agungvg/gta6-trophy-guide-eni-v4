Sunset Ledger — a static, fully offline GTA VI trophy guide and tracker for all 55 PlayStation 5 trophies (1 Platinum, 2 Gold, 6 Silver, 46 Bronze; 28 PSN-hidden). Every trophy shows its official name, description and grade as PlayStation publishes them, plus a guide written in our own words: 189 cited steps across the 55 guides, every step naming its sources, 55/55 guides backed by 2 or more guide sources. The tracker saves progress in the browser (localStorage), exports and imports it as JSON, filters by kind, grade, missable, at-risk, PSN-hidden, disputed and unconfirmed, and has a spoiler shield that hides story trophies until they are earned. The roadmap runs in 3 stages (~200 hours, one playthrough, 4/10 difficulty), the missables page watches the 1 possibly missable trophy plus 8 at-risk ones, and the sources page lists the 7 sources actually read on 21 Nov 2026 with per-source claim counts — and 13 disputes shown both ways, because the sources disagree on the final mission's chapter, the platinum hours, the stranger-chain windows and five unconfirmed methods, and this guide says so instead of silently picking one.

## Run it

```sh
python3 -m http.server --directory app 8080
# then open http://localhost:8080 in desktop Chrome (works with the network off)
```
